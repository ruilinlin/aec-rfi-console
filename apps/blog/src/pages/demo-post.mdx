# Island demo

Static prose rendered by Astro — zero JavaScript — until a component needs to live:

<VerdictStamp client:visible verdict="gap" sub="NO GOVERNING REQ." />

A citation callout hydrates only when scrolled into view, and expands on click
exactly like in the console:

<CitationCallout client:visible n={1} mark="09 90 00" label="Sampling" sourceRef="09 90 00 / 1.7.5.1">
  Provide one liter one quart samples of each part of the selected paint materials.
</CitationCallout>

Everything above shares tokens, fonts, and components with the console app.
